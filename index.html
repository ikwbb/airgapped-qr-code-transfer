How to get a reliable transfer +

1. Open Beam on both devices. Choose Send for a document, any file, or pasted text. Choose Receive on the device with the camera. Use HTTPS or localhost for camera access.

2. Start the camera, then the signal. Keep the code large, square to the camera, and free of glare. For more speed, select two codes and fullscreen, then keep both codes in view. Use one code or a lower speed if the camera struggles.

3. Wait for “File verified”. The sender repeats until you pause it. A one-way visual link cannot tell the sender when the receiver has finished.

Verified text can be copied or saved as a .txt file. Best for small documents. Optical speed depends on your camera, screen, and lighting. Refreshing this page clears transfer progress. Anyone who can see the codes can read the file.
